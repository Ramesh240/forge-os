## Codebase Patterns
- Layout styling: Use semantic CSS variables (`var(--bg-primary)`, `var(--text-primary)`, `var(--border-subtle)`) instead of hardcoded dark hex values (`#060609`).
- Habit data structure: Habit model in `prisma/schema.prisma` contains `currentStreak`, `missedYesterday`, `isReboundPriority`, `downscaledDaysRemaining`, `lastCompletedDate`.
- Android WebView bridge: Check `window.ForgeAndroidBridge` before invoking native methods.
- Dynamic theme sync: Call `applyThemeAndAccentToDocument(theme, accent)` which handles localStorage, DOM attributes (`data-theme`, `data-accent`), `<meta name="theme-color">`, and native Android status bar icon brightness.
